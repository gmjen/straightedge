# Changelog

Straightedge follows Semantic Versioning after `1.0.0`. Before then, prerelease identifiers mark
the public compatibility stage.

## Unreleased

- No unreleased changes yet.

## 0.2.0-alpha.1 — 2026-08-12

- Added deterministic given-order distribution, row, and stack operations with sidecar v3.
- Added scoped diagnostic profiles, replay history, and explainability output.
- Made undo transactional and reset previewable, backed up, and restorable.
- Hardened local editor dirty-state, resize, selection-order, zoom, keyboard, and error flows.
- Added OSS policy, CI, package smoke tests, and reproducible README visual assets.
- Upgraded the pinned browser runtime and added an explicit trusted-CI launch mode.
